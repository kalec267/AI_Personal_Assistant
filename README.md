# LUNA · Windows 개인 비서 응용프로그램

한국어 음성·텍스트로 일정을 정리하고 PC를 제어하는 **네이티브 데스크톱 앱**입니다. Tkinter로 만든 독립 창에서 실행되며 앱 본체에 웹 서버가 필요하지 않습니다. 문서·이미지를 첨부해 Ollama로 분석하고, 뉴스·동영상 검색 결과를 기본 브라우저에서 열 수 있습니다.

## Windows에서 실행

1. **Windows 10/11**에 **[Python 3.12 64비트](https://www.python.org/downloads/release/python-31210/)**를 설치합니다. 다운로드 페이지의 **Windows installer (64-bit)**을 선택하고 설치 옵션의 **Python Launcher**와 **Tcl/Tk and IDLE**을 포함하세요. 설치 스크립트는 마이크 패키지와 호환되는 Python 3.12를 명시적으로 사용합니다. 다른 Python 버전이 함께 설치되어 있어도 됩니다.
2. 저장소 폴더의 **`setup.bat`**을 한 번 실행합니다. 전용 **`.venv-py312`**에 음성 인식 패키지를 설치합니다. 이전 `.venv`와 일정 데이터는 유지됩니다. 인터넷 연결이 필요합니다.
3. **`start.bat`**을 실행하면 루나 앱 창이 열립니다. 이후에는 `start.bat`만 실행하면 됩니다.

업데이트한 버전은 `setup.bat`을 다시 실행해 로컬 음성과 문서 처리 패키지도 설치하세요. **‘설정 → 소리 · 음성 → 로컬 음성 설치’**를 한 번 누르면 약 81MB 모델을 받아 무료 한국어 여성 음성을 사용할 수 있습니다. 터미널 설치를 원하면 `setup_voice.bat`을 실행하세요.

터미널에서 직접 실행할 수도 있습니다.

```powershell
py -3.12 -m venv .venv-py312
.venv-py312\Scripts\python.exe -m pip install --only-binary=PyAudio -r requirements.txt
.venv-py312\Scripts\python.exe -m assistant.app
```

창의 닫기 버튼으로 종료합니다. Windows 설정 → 개인정보 및 보안 → 마이크에서 **데스크톱 앱의 마이크 액세스**를 허용하고 기본 입력 장치를 확인하세요. 마이크 패키지를 설치하지 않아도 텍스트·일정·PC 제어 기능은 사용할 수 있습니다.

## `.exe` 응용프로그램 만들기

Windows에서 `setup.bat` 실행 후 **`build.bat`**을 실행하세요. PyInstaller가 Python과 Tkinter 및 필요한 패키지를 포함한 앱 폴더를 만듭니다.

```text
dist/
  Luna/
    Luna.exe
    _internal/    ← 이 폴더도 함께 배포
```

이후 **`dist\Luna\Luna.exe`**를 더블 클릭하면 됩니다. 배포받는 PC에 Python을 별도로 설치할 필요는 없습니다. `Luna.exe`만 복사하지 말고 **`dist\Luna` 폴더 전체**를 전달하세요. Windows PowerShell, 오디오 장치와 사용할 음성은 대상 PC에 있어야 합니다.

Windows 실행 파일은 **Windows에서 빌드**해야 합니다. 이 Linux 개발 환경에서는 Windows `.exe`와 실제 Windows 오디오 장치를 검증하지 않았습니다. `.github/workflows/windows-build.yml`에는 GitHub Actions의 **Build Windows app → Run workflow**로 테스트·빌드·압축 파일 업로드를 수행하는 구성도 포함되어 있습니다. 저장소에 코드를 올린 뒤 실행할 수 있으며, 이 작업에서 원격 빌드를 실행한 것은 아닙니다.

## 사용 가능한 명령

| 기능 | 예시 |
| --- | --- |
| 일정 초안 | `내일 오후 3시 팀 회의 일정 추가` |
| 분 단위·24시간 | `10월 20일 15:30 병원 일정 등록` |
| 정확한 날짜 | `2026-12-24 오후 6시 저녁 약속 일정 추가` |
| 일정 조회 | `오늘 일정 보여줘`, `내일 일정 알려줘`, `일정 목록` |
| 프로그램 실행 | 직접 등록한 이름으로 `크롬 열어줘`, `크롬 실행해줘`, `크롬 켜줘` |
| 볼륨 | `볼륨 30퍼센트`, `볼륨 올려`, `볼륨 내려` |
| 음소거 | `음소거`, `음소거 해제` |

**‘루나’라고 부르기 → 명령 말하기 → 인식 완료 후 자동 실행** 순서로 사용합니다. 아래의 호출어 모델 설치가 필요하며 기존 마이크 버튼도 사용할 수 있습니다. 인식한 문장은 대화에 표시되며 Enter·보내기·인식 확인 버튼을 누를 필요가 없습니다. 음성으로 요청한 일반 프로그램 실행·볼륨·미디어·검색은 추가 승인 없이 처리합니다. 날짜·시각이 명확한 음성 일정은 바로 저장하며 기본 길이는 1시간입니다. 모호한 `3시`는 오전·오후를 요청하고 저장하지 않습니다. Windows 고급 명령은 명령 전체 확인을 유지합니다. 텍스트 입력은 Enter 또는 ‘보내기’로 전송하고 AI 실행 제안·일정 초안은 기존 확인 창을 사용합니다. 처리 중인 요청이 있으면 중복 녹음·전송하지 않습니다.

### ‘루나’ 호출어로 명령 듣기

1. 변경된 프로젝트에서 **`setup.bat`**을 실행해 새 패키지를 설치합니다.
2. 한 번 **`setup_wake.bat`**을 실행하거나 앱의 **설정 → 소리 · 음성 → ‘호출어 모델 설치 / 다시 시작’**을 누르세요. 공식 Vosk 한국어 소형 모델을 HTTPS로 내려받습니다. 모델 파일은 `%LOCALAPPDATA%\LunaAssistant\models\vosk-model-small-ko-0.22`에 저장합니다. EXE 사용자도 앱의 설치 버튼을 사용할 수 있습니다.
3. **‘루나’라고 부르면 명령 듣기**를 켜고 ‘설정 저장’ 후 설정 창을 닫으세요. 기본값은 켜짐이며 재실행 시 모델이 있으면 감지를 자동 시작합니다. 메인 화면의 **‘호출어 감지 중’** 표시를 확인하세요.
4. **`루나`**라고 부른 뒤 ‘듣고 있어요’가 표시되면 **`크롬 열어줘`**처럼 직접 등록한 이름으로 명령하세요. **`루나, 구글에서 삼성에 대한 기사 찾아줘`**처럼 한 문장으로 이어 말해도 됩니다. 이름만 부르고 명령하지 않으면 약 12초 후 다시 호출을 기다립니다.

호출 감지는 **무료 Vosk 모델로 PC에서 오프라인 처리**하며 호출을 기다리는 소리를 Google이나 Ollama로 계속 전송하지 않습니다. 호출로 시작한 요청의 짧은 오디오(호출어 앞부분을 놓치지 않기 위한 버퍼 포함, 최대 12초)는 기존 Google 한국어 인식으로 전송합니다. 명령 인식에는 인터넷이 필요합니다. 오디오는 메모리에서만 처리하며 녹음 파일은 저장하지 않습니다. 앱 실행 중 기본 마이크를 사용하고 앱 종료 또는 호출 기능 끄기로 감지를 중지합니다. Windows 로그인 자동 실행이나 앱 종료 후 감지는 추가하지 않습니다.

중복 인식을 막기 위해 명령 처리·수동 마이크 사용·설정 창·확인 창이 열려 있는 동안은 호출 감지를 잠시 멈춥니다. 스피커가 읽는 답변을 호출로 오인하지 않도록 **답변 재생 중 감지도 기본적으로 일시 정지**합니다. 이어폰을 사용한다면 **‘답변 재생 중에도 호출 감지’**를 켜서 말하는 중 ‘루나’로 음성을 끊고 새 명령을 줄 수 있습니다. 두 설정 모두 저장됩니다. 오류가 나면 Windows 기본 입력 장치, 데스크톱 앱의 마이크 권한과 `setup_wake.bat` 설치 결과를 확인하세요. 소음·발음·마이크에 따라 호출 인식률이 달라질 수 있으며 마이크 버튼도 계속 사용할 수 있습니다.

일정 목록은 `YYYY-MM-DD` 날짜를 입력하고 ‘조회’를 누르거나 좌우 버튼으로 이동합니다. 일정 선택 후 삭제하거나 ‘내보내기’로 전체 `.ics` 파일을 저장할 수 있습니다. Google Calendar·Outlook에 가져올 수 있으나 자동 동기화 기능은 없습니다. 반복 일정·알림·수정·충돌 검사는 아직 지원하지 않습니다. 변경은 삭제 후 다시 등록하세요.

볼륨은 Windows 기본 재생 장치에 적용합니다. 증감은 10%p이며 음소거를 자동 해제하지 않습니다. **기본 등록 프로그램은 없으며**, 프로그램 실행 도구는 사용자가 직접 등록한 항목만 사용합니다. 이전에 직접 등록한 항목은 유지합니다. Windows 고급 제어는 아래의 별도 설정을 따릅니다.

## 문서·이미지 첨부와 핵심 요약

1. **설정 → AI · 대화**에서 Ollama 로컬 또는 클라우드를 설정합니다.
2. 대화창 아래 **‘파일 첨부’**로 자료를 선택합니다. 첨부 목록 창에서 읽은 텍스트와 읽기 한계를 확인하고 닫으세요.
3. **‘첨부 요약’**을 누르거나 `이 문서의 핵심 주장과 주요 수치를 정리해 줘`, `두 문서를 비교해 줘`, `사진 속 표를 설명해 줘`처럼 질문합니다.
4. 첨부한 자료가 유지된 동안 후속 질문에도 같은 자료를 함께 보냅니다. 첨부 표시를 클릭하면 개별 제거가 가능하며 **‘비우기’**로 일반 대화·PC 명령 모드로 돌아갑니다. ‘새 대화’와 일반 모델·연결 방식 변경도 첨부를 비웁니다.

| 형식 | 읽는 내용과 조건 |
| --- | --- |
| PDF | 텍스트와 페이지 번호. 암호 해제 필요. 스캔 PDF는 OCR 처리하거나 페이지를 이미지로 첨부 |
| PowerPoint `.pptx` | 슬라이드 텍스트·표·차트 계열 값·발표자 메모. Office 설치 불필요 |
| 구형 `.ppt` | Windows에 Microsoft PowerPoint 설치 필요. 매크로를 끄고 읽기 전용으로 열며 `.pptx` 변환을 권장 |
| Excel `.xlsx`, `.xls` | 시트·행별 값. 숨긴 시트도 포함. 수식 실행 없이 저장된 계산값 사용, 계산값이 없으면 수식임을 표시 |
| Word `.docx` | 본문 문단과 표 |
| `.txt`, `.md`, `.csv`, `.json` | UTF-8 또는 CP949 텍스트 |
| PNG·JPG·JPEG·WebP·BMP·TIFF | 이미지 입력을 지원하는 모델로 시각 분석. 여러 프레임 중 첫 프레임 사용 |

이미지는 **설정 → AI · 대화 → ‘이미지 분석 모델’**에 모델을 별도로 지정할 수 있습니다. 빈칸이면 일반 대화 모델을 사용합니다. 예를 들어 로컬에서는 `ollama pull gemma3:4b`로 내려받고 이미지 모델에 `gemma3:4b`를 입력하세요. 텍스트 문서 분석은 일반 모델을 계속 사용하므로 도구 호출용 모델과 구분할 수 있습니다. 클라우드는 해당 계정에서 제공하는 이미지 입력 지원 모델을 지정해야 합니다. 모델의 정확도·메모리 사용량·클라우드 한도는 사용 환경에 따라 다릅니다.

한 번에 파일 **5개**, 파일당 **20MB**, 이미지 **4개**까지 첨부합니다. 문서당 40,000자, 합계 60,000자까지 읽으며 PDF·PPT는 200페이지·슬라이드, Excel은 10시트·시트당 1,000행·40열까지 읽습니다. 읽기 제한은 첨부 안내와 답변에 표시합니다. 긴 텍스트는 구간별 요약 후 통합하므로 여러 요청이 발생할 수 있습니다. PDF·Office 문서 안의 이미지·도형·차트 시각 정보는 자동으로 모두 분석하지 않습니다. 필요한 부분을 이미지로 따로 첨부하세요. 한글 `.hwp`, 구형 Word `.doc`, 매크로 전용 확장자 `.pptm`·`.xlsm`·`.docm`은 지원하지 않습니다.

분석 중에는 PC 실행 도구를 제공하지 않습니다. 첨부 원본을 수정하거나 매크로·수식을 실행하지 않으며, 읽은 텍스트와 변환한 이미지는 현재 앱 메모리에만 보관합니다. 이미지는 긴 변 1600픽셀 이하의 JPEG로 변환하며 EXIF 메타데이터를 전달하지 않습니다. **클라우드 모드에서는 파일 이름·추출한 내용·이미지가 Ollama에 전송**됩니다. 대화 저장을 켜면 파일 이름과 질문·분석 답변은 최근 대화에 저장되지만 원문·이미지 바이트는 별도로 저장하지 않습니다. 앱 재시작 후 원문에 대한 추가 분석에는 파일을 다시 첨부하세요.

## 네이버·구글 뉴스·동영상 검색

상단 **‘뉴스·동영상 검색’**을 누르고 키워드, **네이버/구글**, **전체/뉴스/동영상**을 선택한 뒤 **‘검색 결과 열기’**를 누릅니다. 실제 검색 결과 페이지가 기본 브라우저에 표시됩니다. 검색 서비스·종류 선택은 다음 실행에도 유지됩니다. 검색 API 키나 Ollama 연결 없이 사용할 수 있으며 검색어는 선택한 검색 서비스에 전송됩니다.

대화·음성 입력으로도 사용할 수 있습니다.

- `네이버에서 인공지능 뉴스 검색해줘`
- `구글에서 파이썬 강의 동영상 찾아줘`
- `구글 고양이 사진 검색`

음성·텍스트 명령은 ‘에 대한/에 관한/에 대해서’, ‘관련된’ 같은 명확한 연결 표현과 ‘기사를/동영상을’의 요청 조사를 정리해 키워드로 검색합니다. 예를 들어 **`구글에서 삼성에 대한 기사 찾아줘` → `삼성 기사`**로 구글 뉴스 결과를 엽니다. `대한항공`, 날짜·숫자, `site:` 같은 검색 연산자와 따옴표 안의 정확한 문구는 보존합니다. 직접 검색창에 입력한 검색어는 그대로 사용하며, Ollama가 제안한 검색어에도 같은 정리를 적용합니다.

첨부 분석 모드에서는 ‘비우기’ 후 검색하거나 상단 검색 버튼을 사용하세요. 앞선 대화의 `그걸 뉴스로 찾아줘`처럼 문맥이 필요한 표현은 Ollama가 검색 동작을 제안할 수 있으며 실행 확인 후 결과 페이지를 엽니다. 이 기능은 검색 결과를 여는 기능으로, 앱 안에서 기사·영상 내용을 자동 수집·요약하거나 영상을 재생하지는 않습니다. 검색 서비스의 로그인·접근 제한은 해당 브라우저에서 처리합니다.

## 무료 로컬 여성 음성

기본 선택은 **Supertonic 2 한국어 여성 음성**입니다. ‘설정 → 소리 · 음성’의 ‘로컬 음성 설치’로 모델을 한 번 내려받고 `local:F1`~`local:F5` 중 선택한 뒤 ‘들어보기’를 누르세요. 다운로드와 패키지 설치 이후 **음성 출력은 CPU에서 오프라인으로 실행**하며 API 키나 음성 서비스 요금이 필요 없습니다. GPU는 필요하지 않습니다. 첫 출력은 모델을 메모리에 읽느라 시간이 걸릴 수 있습니다.

모델은 [sherpa-onnx 공식 배포](https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models)의 `sherpa-onnx-supertonic-tts-int8-2026-03-06.tar.bz2`를 사용합니다. 공개 SHA-256 `8c74359f63edd5045d47747f65331f0f6dbcbc91d7e898dd756d631295fe3259`와 비교한 뒤 설치하며 검증 실패 시 사용하지 않습니다. 모델의 MIT 라이선스 파일은 다운로드 폴더에 보존합니다. F1~F5는 배포 모델의 여성 프리셋으로 개인 목소리 복제 기능은 아닙니다.

모델은 `%LOCALAPPDATA%\LunaAssistant\models`에 저장하며 `.exe`에 함께 넣지 않습니다. 따라서 배포한 앱에서도 한 번 설치해야 합니다. Windows 기본 음성을 원하면 같은 목록의 설치 음성을 선택하세요.

### 음성 출력 속도

**설정 → 소리 · 음성 → ‘음성 출력 속도’**에서 **0.5~2.0배**로 조절합니다. 1.0배가 기본이며 ‘기본 속도’ 버튼으로 돌아갈 수 있습니다. 저장 전에도 ‘목소리 들어보기’가 현재 슬라이더 속도로 재생됩니다. **‘설정 저장’** 후 다음 음성 답변부터 적용하며 재실행 후에도 유지됩니다. 로컬 Supertonic은 합성 속도 배율을 사용하며 Windows 설치 음성은 System.Speech의 가까운 속도 단계로 변환하므로 음색에 따라 체감 속도가 다를 수 있습니다.

### Windows 설치 음성

‘설정 → 소리 · 음성’에서 Windows에 설치된 음성을 선택하고 **‘들어보기’**로 확인하세요. Windows `System.Speech`의 **한국어(`ko-KR`)·여성(`Female`) 정보**를 가진 음성을 기본 선택합니다. 여성 음성이 없으면 설치 안내를 표시하며 자동으로 남성 음성을 선택하지 않습니다. 목록에서 사용자가 다른 음성을 직접 선택할 수 있습니다.

한국어 여성 음성이 없다면 Windows 설정 → 시간 및 언어 → 음성에서 한국어 음성 패키지를 설치한 뒤 앱을 다시 시작하세요. `System.Speech`에 노출되는 음성만 사용할 수 있어 Windows 내레이터·브라우저의 모든 음성이 표시되지는 않습니다. 음성 선택과 ‘답변 읽기’ 설정은 PC에 저장됩니다.

음성을 듣는 중 **새 명령을 전송(Enter 또는 전송 버튼)**하거나 **마이크를 켜면** 기존 음성을 즉시 중지합니다. 이전 답변의 대기 중인 재생과 합성 결과도 취소하므로 뒤늦게 다시 읽지 않으며, 새 명령의 답변이 준비되면 선택한 목소리와 속도로 읽습니다. 로컬 Supertonic과 Windows 설치 음성 모두에 적용됩니다. 로컬 모델이 이미 합성 중이면 해당 계산은 끝날 수 있지만 취소된 소리는 재생하지 않습니다. 답변 읽기를 끄거나 앱을 종료할 때도 현재 음성과 대기 요청을 취소합니다.

**명령 음성 인식은 인터넷이 필요하며 Google 음성 서비스로 요청 오디오를 HTTPS 전송**합니다. 호출어 대기는 위 Vosk 모델로 로컬 처리하고, 로컬 TTS는 음성 출력을 오프라인으로 처리합니다. SpeechRecognition의 기본 Google 명령 인식 연동을 사용하므로 서비스 가용성·사용 제한에 영향을 받습니다. 인식 실패 시 텍스트를 입력하세요. 로컬 음성 재생에 필요한 임시 WAV는 재생 후 삭제하며 마이크 기록은 영구 저장하지 않습니다. 대화 텍스트는 설정에서 저장을 선택한 경우에만 저장합니다.

## Ollama로 자연어 명령 인식

앱 상단 **‘설정’**에서 연결 방식을 선택합니다. 기본 상태는 ‘AI 끔’이며 이때 기존의 정해진 명령이 동작합니다.

- **Ollama 로컬**: [Ollama](https://ollama.com/download)를 Windows에 설치하고 실행합니다. 터미널에서 `ollama pull qwen3:4b`로 모델을 한 번 받은 뒤 앱의 모델 이름을 `qwen3:4b`로 저장하고 ‘연결 테스트’를 누르세요. API 키가 필요 없고 PC에서 추론하므로 API 사용료가 없습니다. 모델 용량과 RAM 사용량은 PC에서 확인하세요. 도구 호출을 지원하는 다른 모델로 변경할 수도 있습니다.
- **Ollama 클라우드**: [Ollama 키 설정](https://ollama.com/settings/keys)에서 만든 키를 앱의 가려진 입력란에 등록하고 모델을 `gpt-oss:120b` 등 계정에서 사용 가능한 도구 호출 모델로 설정하세요. Windows에서는 현재 사용자 계정의 DPAPI로 암호화 저장합니다. 체크를 해제하면 앱을 닫을 때까지 메모리에서만 사용합니다. 키를 코드·채팅·설정 JSON에 기록하지 마세요. 노출된 키는 폐기 후 재발급하세요.

클라우드 모드는 계정별 사용 한도와 요금 정책이 적용되므로 무제한 무료를 보장하지 않습니다. 외부 API 요금 없이 사용하려면 로컬 모드와 로컬 음성을 선택하세요. 클라우드 키는 `https://ollama.com/api/chat`에만 보내며 로컬 모드에는 보내지 않습니다. 환경 변수 `LUNA_OLLAMA_API_KEY` 또는 `OLLAMA_API_KEY`도 지원합니다. UI에서 새 키를 입력하면 해당 세션의 입력값을 우선 사용합니다.

### 요청 예시와 실행 확인

- `크롬을 켜고 소리는 25퍼센트로 맞춰줘` (크롬 등록 후)
- `유튜브 https://www.youtube.com 을 열어줘`
- `음악 잠깐 멈춰줄래?`
- `내일 오후 3시에 프로젝트 회의를 한 시간 잡아줘`
- 직접 등록한 프로그램에 대해 `크롬 실행해 줘`

AI는 실행할 동작을 최대 5개까지 제안합니다. 텍스트로 요청한 동작은 앱에서 **구체적인 실행 목록을 보고 확인**합니다. 음성 요청은 프로그램·소리·미디어·검색 동작을 바로 실행하고 결과만 안내합니다. 파일·시스템 설정 등을 다루는 Windows 고급 명령은 음성 요청에도 명령 전체 확인이 필요합니다. 취소하면 실행하지 않습니다. 확인 제안은 5분 후 만료되며 중복 실행되지 않습니다. 여러 동작 중 하나가 실패하면 그 이후 동작을 멈추며 이미 완료된 동작은 되돌리지 않습니다. 텍스트 일정은 별도 초안 창에서 날짜·시간을 확인하고 저장하며, 명확한 음성 일정은 자동 저장합니다. 일정 추가와 다른 동작은 나누어 요청하세요. 조회는 저장된 로컬 데이터로 답합니다.

AI에 전달되는 정보는 이번 입력, **최근 질문·답변**, 현재 PC 시각, 등록한 프로그램의 **이름과 ID**입니다. 첨부 분석 시에는 파일 이름·추출한 텍스트·변환한 이미지도 전달합니다. 등록 목록의 프로그램 경로나 설정 창에 등록한 API 키를 자동으로 대화에 넣지 않습니다. 이전 대화에서 조회한 일정, 제안한 Windows 명령과 실행 결과는 최근 답변의 일부로 포함될 수 있습니다. Windows 고급 제어를 켜면 관리자 권한 여부도 전달합니다. 인식 오류나 모델의 잘못된 해석이 있을 수 있으므로 실행 목록을 확인하세요.

### 최근 대화 이어가기

이제 ‘내 이름은 민수야’ 다음에 ‘내 이름이 뭐였지?’처럼 앞선 대화를 이어갈 수 있습니다. 기본값은 최근 **10회 질문·답변**이며 ‘설정 → AI · 대화’에서 1~20회로 조절합니다. 문맥 길이를 제한하기 위해 전체 약 20,000자를 넘으면 오래된 질문·답변부터 제외합니다.

기본 상태에서는 현재 앱 세션에서만 기억합니다. **‘최근 대화를 이 PC에 저장해 앱 재시작 후에도 이어가기’**를 선택하고 ‘설정 저장’을 누르면 최근 대화를 `conversation.json`에 저장하고 다음 실행 때 복원합니다. 이 파일은 암호화되지 않은 개인 파일입니다. 클라우드 모드에서는 최근 대화도 Ollama에 전송됩니다. 저장 옵션을 끄면 디스크 기록을 지우고 현재 세션 기억만 유지합니다.

메인 화면의 **‘새 대화’**로 최근 기록과 대기 중인 실행 제안을 초기화할 수 있습니다. 연결 방식이나 모델을 바꾸면 다른 모드에 이전 대화를 전달하지 않도록 새 대화를 시작합니다. 실행 이력은 ‘제안·취소·완료’ 상태의 텍스트만 기억하며 과거 도구 호출을 다시 실행하지 않습니다. 새 음성 요청의 일반 동작은 바로 실행하며 텍스트 요청과 Windows 고급 명령은 실행 목록을 확인합니다.

### 통합 사용자 설정

메인 화면의 **‘설정’ 버튼 하나**에서 모든 사용자 설정을 관리합니다.

- **AI · 대화**: 연결 방식, 일반·이미지 분석 모델, 키, 최근 대화 수, 재시작 후 기록 유지.
- **프로그램**: 사용자 지정 이름과 실행 파일 등록·삭제. 목록 변경은 즉시 저장됩니다.
- **소리 · 음성**: 여성 음색 선택, 출력 속도, 답변 읽기, 목소리 미리 듣기, 로컬 모델 설치, 볼륨·음소거.
- **Windows 제어**: 고급 명령 허용, 현재 권한 확인, 설정 저장 후 관리자 권한으로 재실행.

설정 창 하단의 **‘설정 저장’**을 누르면 선택한 AI·목소리·출력 속도·답변 읽기·볼륨 기본값·대화 옵션·Windows 제어 허용을 함께 저장합니다. 볼륨의 ‘지금 볼륨 적용’은 현재 PC 소리를 바꾸며, 저장한 볼륨을 다음 실행 때 자동 적용하려면 해당 옵션을 켜세요. 기본 상태에서는 앱 시작만으로 PC 볼륨을 바꾸지 않습니다.

### 프로그램 추가

처음 프로그램 목록은 비어 있습니다. **설정 → 프로그램**에서 다음처럼 추가하세요.

1. **부를 이름**에 `크롬`을 입력합니다.
2. **‘.exe 선택’**을 눌러 설치된 `chrome.exe`를 선택합니다. 바탕 화면 바로가기 `.lnk` 대신 실제 실행 파일을 선택하세요.
3. **‘등록’**을 누릅니다. 등록은 즉시 `programs.json`에 저장되어 재실행 후에도 유지됩니다.
4. 설정 창을 닫고 **`루나, 크롬 열어줘`**라고 부르거나 마이크 버튼을 눌러 **`크롬 실행해줘`**, **`크롬 켜줘`**라고 말하세요. 텍스트로도 사용할 수 있습니다.

이름으로 실행하는 단일 명령은 **Ollama 연결 없이도** 동작합니다. 띄어쓰기와 영문 대소문자 차이는 허용하지만 비슷한 이름을 임의로 추측해 실행하지 않습니다. 중복 이름은 등록할 수 없으며, 필요한 경우 같은 `.exe`를 `크롬`, `Chrome`처럼 서로 다른 이름으로 등록할 수 있습니다. 등록하지 않은 프로그램은 기본 명령 모드에서 프로그램 설정으로 안내합니다. AI 모드의 정확한 이름 명령도 모델 호출 없이 기존 실행 제안을 만들며, 음성은 바로 실행하고 텍스트는 확인 후 실행합니다. 복합 요청은 기존 Ollama 처리를 사용합니다.

등록 앱 실행 도구는 저장된 실행 파일만 사용하며 임의 경로나 실행 인자를 받지 않습니다. 등록을 삭제해도 설치된 프로그램 파일은 삭제하지 않습니다. 별도로 Windows 고급 제어를 켜면 PowerShell 명령을 통한 프로그램·파일·시스템 조작도 제안할 수 있습니다.

### Windows 고급 제어와 관리자 권한

1. **설정 → AI · 대화**에서 Ollama 로컬 또는 클라우드를 선택합니다.
2. **설정 → Windows 제어 → ‘Windows 고급 제어 허용 (PowerShell 명령)’**을 켜고 **‘설정 저장’**을 누릅니다. 허용 여부는 재실행 후에도 유지됩니다.
3. 관리자 작업이 필요하면 같은 탭의 **‘설정 저장 후 관리자 권한으로 다시 실행’**을 누르고 Windows **UAC 창에서 직접 승인**합니다. 승인 요청을 취소하면 기존 앱이 유지됩니다. 소스 실행과 빌드된 `.exe` 모두 같은 데이터 폴더로 다시 실행합니다.
4. 작업을 요청하고, 스크롤 가능한 확인 창에서 **실제 PowerShell 명령 전체**를 확인한 뒤 ‘위 명령 실행’을 누릅니다. 취소하면 실행하지 않습니다.

예: `내 문서 폴더에 프로젝트라는 폴더 만들어 줘`, `지금 실행 중인 메모장 프로세스 보여 줘`, `블루투스 설정 창 열어 줘`. 파일 생성·이동·이름 변경·삭제, 임의 프로그램 실행·프로세스 종료, 서비스·레지스트리·시스템 설정 등 **현재 Windows 계정이 허용하는 작업**을 PowerShell 5.1로 실행합니다. 고급 제어를 끄고 저장하면 승인 대기 중인 Windows 명령도 실행 시 차단됩니다. 기본 도구는 계속 사용할 수 있습니다.

고급 제어 명령은 경로나 실행 대상의 별도 허용 목록으로 제한하지 않습니다. 삭제·종료·설정 변경은 실제 PC에 적용되며 자동으로 되돌리지 않습니다. 권한 상승은 이번 앱 실행에 적용되며 UAC나 보안 정책을 우회하지 않습니다. 관리자여도 보호된 프로세스·다른 계정의 암호화 데이터·조직 정책 등 Windows 제한을 없애지는 못합니다. 세션에만 보관한 API 키는 재실행 후 다시 입력해야 하며, 다른 관리자 계정으로 승인했다면 DPAPI 키도 다시 등록해야 합니다. 재시작 후 대화 유지는 별도 옵션입니다.

명령은 비대화형으로 실행하며 30초를 넘으면 프로세스 트리 중단을 요청합니다. 이미 적용된 변경과 별도로 시작된 작업까지 취소하는 기능은 아닙니다. 실행 출력은 길이를 제한해 대화에 표시합니다. **명령과 결과가 최근 대화에 포함되므로 클라우드 모드에서는 후속 요청에 함께 전송됩니다.** 비밀 키·암호·민감한 파일 내용을 조회하는 명령은 요청하지 마세요. 이 기능은 앱 화면을 지속적으로 관찰하며 자율적으로 조작하는 기능은 아닙니다.

## 데이터 저장 위치

일정은 `%LOCALAPPDATA%\LunaAssistant\calendar.sqlite3`, 음성 설정은 같은 폴더의 `settings.json`에 저장합니다. 이전 버전의 Windows 일정 저장 경로와 동일하여 기존 일정을 그대로 읽습니다. 앱을 닫아도 유지됩니다. 백업하려면 앱을 종료한 뒤 이 폴더를 복사하세요. 다른 데이터 폴더는 다음처럼 지정할 수 있습니다.

```powershell
.venv-py312\Scripts\python.exe -m assistant.app --data-dir "D:\LunaData"
```

AI 모드·음성·사운드·대화 옵션·Windows 제어 허용은 `settings.json`, 등록한 프로그램 목록은 `programs.json`, 암호화한 키는 `ollama-key.dpapi`에 따로 저장합니다. DPAPI 키 파일은 저장한 Windows 사용자 계정에서만 복호화할 수 있으므로 다른 PC로 옮긴 뒤에는 키를 다시 입력하세요. 전체 폴더 백업에는 암호화된 키와 등록 경로, 저장을 선택한 경우 최근 대화가 포함됩니다.

## 문제 해결과 개발 검증

- `AI API 인증·접근 권한을 확인해 주세요`라는 이전 문구: 기본 명령 모드에서 남아 있던 OpenAI 연결이 실행될 때 발생하던 오류입니다. 최신 버전에서는 AI를 끄면 외부 AI에 연결하지 않습니다. 앱을 종료하고 최신 코드의 `setup.bat` → `start.bat`으로 실행한 뒤 ‘설정’ → ‘Ollama 클라우드’ → ‘Ollama API 키’ 등록 → ‘설정 저장’ → ‘연결 테스트’ 순서로 확인하세요. Ollama 키는 `LUNA_OPENAI_API_KEY`에 넣지 않습니다. 상단에 설정 버튼이 없다면 이전 버전 앱을 실행 중인 것입니다. 기존 `.exe`는 소스 코드만 업데이트해도 바뀌지 않으므로 다시 빌드하거나 `start.bat`을 사용하세요.
- 마이크 오류: `setup.bat` 설치 결과, Windows 기본 입력 장치와 데스크톱 앱 마이크 권한을 확인하세요.
- 음성·볼륨 오류: Windows PowerShell과 기본 출력 장치가 필요합니다. 조직 정책이 `.ps1` 실행을 차단하면 승인·서명 절차를 따르세요. 앱은 실행 정책을 우회하지 않습니다.
- PyAudio 설치 중 `portaudio.h` 오류: 이전 설치 스크립트가 Python 3.14 등을 선택하면 호환 휠 대신 소스 빌드를 시도할 수 있습니다. Python 3.12 64비트를 추가 설치하고 최신 `setup.bat`을 실행하세요. 전용 `.venv-py312`를 만들기 때문에 기존 `.venv`를 삭제할 필요가 없습니다. 수정된 스크립트는 PyAudio의 사전 빌드된 휠만 설치합니다.
- 시작 오류: 터미널에서 `.venv-py312\Scripts\python.exe -m assistant.app`을 실행해 출력을 확인하세요. Python의 Tcl/Tk가 설치되어 있어야 합니다.
- Linux 개발: `python -m assistant.app --data-dir /tmp/luna-dev`로 독립 창과 일정을 검증할 수 있습니다. GUI 디스플레이가 필요하며 Windows PC 제어·음성 출력은 사용할 수 없습니다.

```powershell
.venv-py312\Scripts\python.exe -m unittest discover -v
```

테스트는 명령 해석·데이터 영속성·일정 내보내기·네이티브 UI의 초안 확인·저장·재실행·삭제·AI 제안 승인과 취소·허용 동작 검증·자격 증명 보관을 검증합니다. 최근 대화의 요청 포함·길이 제한·초기화·선택적 저장과 통합 사용자 설정의 재실행 복원도 확인합니다. Windows 고급 제어의 허용·차단·권한 변경·명령 확인·오류·시간 초과도 검사합니다. 실제 PDF·PPTX·XLSX·XLS·DOCX·이미지 읽기, 첨부 요청·후속 질문과 검색어 인코딩·브라우저 호출도 검사합니다. GUI 테스트는 Linux에 디스플레이가 없으면 건너뛰며 실제 DPAPI와 PowerShell 한글 출력·종료 코드 검사는 Windows에서만 실행합니다. UAC·Windows 장치·외부 Ollama는 모의 호출로 검증하므로 실제 PC에서의 확인을 대체하지 않습니다. 이전 웹 버전의 회귀 테스트도 유지됩니다.
